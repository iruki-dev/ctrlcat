## CSV JSON 변환기

## 어떤 도구인가요

스프레드시트나 데이터베이스는 보통 쉼표로 구분된 텍스트 행을 내보냅니다. 반면 대부분의 웹 도구와 앱은 같은 정보를 JSON 형태로 받고 싶어 합니다. 이 둘을 손으로 바꾸는 일은 느리고 실수가 생기기 쉽습니다.

이 도구는 양방향 변환을 모두 처리합니다. CSV를 붙여넣으면 행마다 하나의 객체가 담긴 JSON 배열이 나오고, 첫 줄은 필드 이름으로 쓰입니다. JSON을 붙여넣으면 레코드에서 모은 머리글과 함께 CSV가 돌아옵니다. 모든 처리는 브라우저 안에서 이루어지므로 데이터는 기기를 떠나지 않습니다.

## 어떤 때에 쓸 수 있나요

스프레드시트에서 내보낸 목록을 테스트 데이터베이스에 넣기 위해 JSON으로 바꿔야 할 때 쓸 수 있습니다.

JSON으로 받은 API 응답을 스프레드시트에서 정렬하고 걸러 보고 싶을 때 쓸 수 있습니다.

쉼표가 들어 있는 인용부호로 묶인 칸을 쪼개지 않고 올바르게 읽어야 할 때 쓸 수 있습니다.

붙여넣은 데이터의 행과 열이 실제로 몇 개인지 다른 곳으로 보내기 전에 확인하고 싶을 때 쓸 수 있습니다.

## 사용 방법

먼저 위쪽에서 방향을 고릅니다. CSV를 JSON으로 바꿀지, JSON을 CSV로 바꿀지 선택합니다.

입력 칸에 데이터를 붙여넣습니다. CSV의 경우 머리글 줄이 있다면 첫 줄에 그대로 두시면 됩니다.

파일이 쉼표가 아닌 다른 구분자를 쓴다면 구분자를 바꿉니다. 스프레드시트에서 바로 복사한 데이터에는 탭이 잘 맞습니다.

CSV 입력에서는 머리글 줄 사용을 끌 수도 있습니다. 이때 필드 이름은 위치에 따라 매겨집니다.

변환 버튼을 누릅니다. 결과가 아래에 나타나고 행과 열의 개수도 함께 보입니다. 복사 버튼으로 결과를 가져가거나, 지우기 버튼으로 처음부터 다시 시작할 수 있습니다.

## 자주 묻는 질문

**데이터가 어딘가로 전송되나요?**
전송되지 않습니다. 변환은 브라우저 안에서 이루어지며 서버로 아무것도 보내지 않습니다. 온라인 서비스에 올리기 꺼려지는 데이터도 안심하고 붙여넣을 수 있습니다.

**인용부호로 묶인 칸과 줄바꿈은 어떻게 처리되나요?**
인용부호로 묶인 칸은 안에 구분자나 줄바꿈, 두 번 연달아 쓴 큰따옴표가 들어 있어도 하나의 값으로 읽힙니다. 다시 CSV로 바꿀 때는 묶어야 하는 값에 인용부호를 자동으로 붙여 줍니다.

**JSON에 빈 값이 들어가는 이유는 무엇인가요?**
어떤 행의 값 개수가 머리글보다 적으면 빠진 필드는 빈 문자열로 채워집니다. 그래서 모든 레코드가 같은 모양을 유지합니다. 머리글보다 값이 많으면 번호가 붙은 이름이 주어집니다.

**숫자는 숫자로 유지되나요?**
CSV에는 자료형이 없으므로 기본적으로 모든 값이 문자열이 됩니다. 숫자와 참 또는 거짓 값 인식을 켜면 숫자와 true, false가 실제 JSON 값으로 변환됩니다.
