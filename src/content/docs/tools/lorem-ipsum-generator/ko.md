## 로렘 입숨 생성기

## 이 도구는 무엇인가요

로렘 입숨은 수백 년 동안 인쇄와 디자인 분야에서 쓰여 온 채움용 텍스트입니다. 언어처럼 보이지만 의미를 담고 있지 않아, 보는 사람이 글을 읽는 대신 배치에 집중하게 됩니다. 이 도구는 필요한 분량만큼 그 채움 텍스트를 만들어 줍니다.

문단, 문장, 단어 중 어떤 단위로 셀지 고르고 원하는 개수를 정하면 결과가 바로 나타납니다. 모든 작업은 브라우저 안에서 처리되므로 생성한 내용이 외부로 전송되지 않습니다.

## 어떤 때 쓰면 좋은가요

실제 문구가 준비되기 전에 여백과 글자 크기를 검토할 수 있도록 시안 페이지를 채울 때 사용합니다.

생각했던 예시보다 글이 훨씬 길어졌을 때 카드, 표 칸, 제목이 어떻게 보이는지 확인할 때 사용합니다.

본문처럼 보이는 데이터가 필요한 데이터베이스나 콘텐츠 모델에 초기 자료를 넣을 때 사용합니다.

입력란, 댓글 상자, 미리 보기 카드가 의도대로 줄을 바꾸고 말줄임 처리하는지 점검할 때 사용합니다.

문구 승인은 아직 끝나지 않았지만 디자인 검토 일정이 잡힌 인쇄물 작업을 준비할 때 사용합니다.

## 사용 방법

단위를 먼저 고릅니다. 문단, 문장, 단어 중에서 선택할 수 있습니다. 그다음 개수 칸에 필요한 수량을 입력합니다. 익숙한 "Lorem ipsum dolor sit amet" 문장으로 시작하고 싶다면 첫 문장 옵션을 켠 채로 두고, 매번 다른 문장으로 시작하고 싶다면 끕니다.

생성 버튼을 누르면 아래쪽에 결과가 단어 수와 글자 수와 함께 표시됩니다. 복사 버튼을 누르면 클립보드에 담기고, 생성 버튼을 다시 누르면 새 문장이 만들어집니다. 지우기 버튼은 결과를 비웁니다.

**한 번에 얼마나 만들 수 있나요?**

**이 글에 뜻이 있나요?**

**생성한 글이 어딘가에 저장되나요?**
저장되지 않습니다. 글은 브라우저에서 만들어지며 페이지를 닫거나 새로 고치면 사라집니다.
