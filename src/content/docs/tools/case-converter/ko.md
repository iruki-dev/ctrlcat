## 대소문자 변환기

## 이 도구는 무엇인가요

텍스트는 원하는 모양으로 들어오지 않을 때가 많습니다. 제목이 전부 대문자로 복사되기도 하고, 변수 이름이 밑줄을 쓰는데 프로젝트 규칙은 하이픈이기도 합니다. 붙여넣은 문장 곳곳에 대문자가 섞여 있기도 합니다.

이 도구는 입력한 텍스트를 아홉 가지 표기 방식으로 한 번에 보여 줍니다. 필요한 것을 골라 복사하면 됩니다. 모든 처리는 브라우저 안에서 이루어지므로 개인 메모나 사내 코드를 붙여넣어도 괜찮습니다.

## 어떤 때 쓰면 좋은가요

변수 이름을 바꾸는 중인데 새 프로젝트가 카멜 표기 대신 스네이크 표기를 쓸 때 사용합니다.

전부 대문자로 작성된 문서에서 제목을 가져와 웹 페이지용 제목 표기로 바꿀 때 사용합니다.

CSS 클래스나 파일 이름을 지으면서, 이미 적어 둔 단어를 케밥 표기로 바꾸고 싶을 때 사용합니다.

보통 밑줄과 대문자로 쓰는 환경 변수 이름이 필요할 때 사용합니다.

대문자 사용이 들쭉날쭉한 문단을 깔끔한 문장 표기로 되돌리고 싶을 때 사용합니다.

## 사용 방법

입력 상자에 텍스트를 붙여넣거나 입력합니다. 모든 결과는 입력하는 즉시 갱신되므로 따로 누를 버튼이 없습니다.

결과 목록을 훑어보며 원하는 표기를 찾습니다. 각 줄에 변환된 전체 텍스트가 표시됩니다.

해당 줄의 복사 버튼을 누르면 클립보드에 담깁니다.

지우기를 누르면 입력 상자가 비워집니다. 결과 위의 숫자는 지금 다루고 있는 글자 수, 단어 수, 줄 수를 알려 줍니다.

## 자주 묻는 질문

**여러 단어나 여러 줄도 처리하나요?**
가능합니다. 대문자, 소문자, 제목, 문장 표기는 줄 바꿈과 띄어쓰기를 그대로 유지합니다. 카멜이나 스네이크 같은 프로그래밍용 표기는 입력 전체를 하나의 이름으로 다루기 때문에, 공백과 문장 부호는 단어 구분 기호로 쓰이고 결과에서는 사라집니다.

**getUserName 같은 단어는 어떻게 나누나요?**
소문자 뒤에 대문자가 오는 지점을 단어 경계로 봅니다. 대문자가 연달아 나오는 경우도 처리하므로 HTTPServer는 http와 server 두 단어로 나뉩니다. 덕분에 프로그래밍용 표기끼리 양방향으로 바꿀 수 있습니다.

**악센트 문자나 한글 같은 글자는 어떻게 되나요?**
그대로 유지됩니다. 대문자와 소문자 변환은 해당 문자의 규칙을 따르며, 대소문자 구분이 없는 글자는 바뀌지 않고 그대로 지나갑니다.

**입력한 내용이 어딘가로 전송되나요?**
아닙니다. 모든 처리는 브라우저 안에서 이루어지며, 페이지를 닫은 뒤에 남는 기록도 없습니다.
