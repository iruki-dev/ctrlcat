## 마크다운 미리보기란 무엇인가요

마크다운은 몇 가지 문장 부호 규칙으로 서식을 대신하는 일반 텍스트입니다. 우물 정 기호는 제목이 되고, 별표는 글자를 굵게 만들며, 붙임표는 목록 항목을 시작합니다. 문제는 무언가가 실제로 변환해 주기 전까지는 문서가 어떻게 보일지 알 수 없다는 점입니다.

이 도구는 입력하는 즉시 변환해 보여 줍니다. 원본 텍스트는 왼쪽에 남고 서식이 적용된 문서는 오른쪽에 나타나며, 두 화면은 항상 같은 내용을 유지합니다. 어디에도 업로드되지 않고 변환은 브라우저 안에서만 이루어집니다.

## 어떤 상황에 유용한가요

- 저장소에 올리기 전에 README를 확인하여 제목과 표가 의도한 대로 나오는지 점검할 때 유용합니다.
- 블로그 글이나 뉴스레터를 마크다운으로 작성한 뒤, 발행 시스템에 붙여 넣기 전에 구조를 확인할 때 쓸 수 있습니다.
- 목록과 표가 정확히 맞아야 하는 릴리스 노트나 변경 이력을 작성할 때 도움이 됩니다.
- 다른 사람이 작성한 파일을 원본 텍스트로만 받았고 변환된 화면이 없을 때 내용을 살펴볼 수 있습니다.
- 마크다운 초안에서 일반 HTML을 가져와 이메일 템플릿이나 페이지 편집기에 넣을 때 활용할 수 있습니다.

## 사용 방법

왼쪽 영역에 마크다운을 입력하거나 붙여 넣으십시오. 오른쪽 영역이 즉시 갱신되므로 따로 누를 버튼이 없습니다.

오른쪽 영역은 미리보기와 HTML 사이를 오갈 수 있습니다. 미리보기는 서식이 적용된 문서를 보여 주고, HTML은 생성된 마크업을 보여 줍니다. 마크업은 영역 위쪽의 버튼으로 복사할 수 있습니다.

지원하는 기능을 확인하고 싶다면 예시 불러오기를 누르십시오. 제목, 목록, 표, 인용문, 코드 블록, 링크를 사용한 문서가 편집기에 채워집니다. 처음부터 다시 시작하려면 지우기를 누르면 됩니다.

아래쪽의 수치는 단어 수, 글자 수, 줄 수, 그리고 분당 200단어를 기준으로 계산한 예상 읽기 시간을 보여 줍니다.

## 자주 묻는 질문

**어떤 마크다운 기능을 지원하나요?**
제목, 굵게, 기울임, 취소선, 인라인 코드, 코드 블록, 한 단계 중첩까지 포함한 순서 있는 목록과 순서 없는 목록, 인용문, 구분선, 링크, 이미지, 정렬을 지원하는 표를 다룹니다. 마크다운 안에 들어 있는 HTML은 그대로 실행되지 않고 글자로 표시되므로, 직접 작성하지 않은 파일을 열어 볼 때도 안전합니다.

**작성한 내용이 외부로 전송되나요?**
전송되지 않습니다. 모든 처리는 브라우저 탭 안에서 이루어지며 서버로 보내거나 저장하지 않습니다. 탭을 닫으면 초안이 사라지므로 중요한 내용은 따로 보관하시기 바랍니다.

**깃허브에서 보이는 모습과 똑같은가요?**
구조는 같지만 겉모습은 다릅니다. 사이트마다 변환된 마크다운에 각자의 글꼴과 여백, 색을 적용하기 때문입니다. 최종 디자인을 판단하기보다는 제목과 목록, 표가 올바른지 확인하는 용도로 사용하십시오.

**HTML 결과를 그대로 써도 되나요?**
됩니다. HTML 화면에는 스타일 클래스가 포함된 마크업이 나옵니다. 다른 시스템에 넣기 위해 순수한 마크업이 필요하다면 복사한 뒤 클래스 속성을 지우면 됩니다.
