## 이 도구는 무엇인가요

해시는 어떤 데이터의 짧은 지문입니다. 같은 텍스트나 같은 파일을 넣으면 항상 같은 지문이 나옵니다. 글자 하나만 바뀌어도 결과는 완전히 달라집니다.

이 도구는 입력한 텍스트나 선택한 파일을 그 지문으로 바꿉니다. SHA-1, SHA-256, SHA-384, SHA-512 계열을 지원합니다. 모든 계산은 브라우저에 내장된 암호화 기능으로 처리되므로, 텍스트와 파일은 사용자의 컴퓨터를 떠나지 않습니다.

## 어디에 쓰면 좋은가요

다운로드한 파일을 확인할 때입니다. 많은 프로젝트가 배포 파일 옆에 SHA-256 값을 함께 공개합니다. 내려받은 파일의 해시를 구해 두 문자열을 비교하면 파일이 온전히 도착했는지 확인할 수 있습니다.

문서나 설정 파일이 바뀌었는지 확인할 때입니다. 지금 해시를 기록해 두고 나중에 다시 구해 보면, 그동안 수정이 있었는지 알 수 있습니다.

패키지 관리자나 배포 스크립트에 넣을 체크섬 값을 채워야 할 때입니다.

해시를 비교하는 프로그램을 시험할 때, 기준이 될 값이 필요한 경우입니다.

## 사용 방법

필요한 알고리즘을 고릅니다. 보통은 SHA-256을 씁니다.

텍스트라면 입력란에 직접 쓰거나 붙여 넣고 생성을 누릅니다. 파일이라면 파일 탭으로 바꾸고 컴퓨터에서 파일을 선택합니다.

결과는 소문자 16진수 문자열로 표시됩니다. 복사 버튼을 누르면 클립보드에 담깁니다.

이미 가지고 있는 값을 확인하려면 비교란에 붙여 넣으십시오. 대소문자와 앞뒤 공백은 무시하고 일치 여부를 알려 줍니다.

## 자주 묻는 질문

**파일이 어딘가로 전송되나요?**
아닙니다. 파일은 페이지가 직접 읽어 사용자의 기기 메모리에서 처리합니다. 서버를 거치지 않으며, 페이지를 벗어나거나 새로 고치면 아무것도 남지 않습니다.

**어떤 알고리즘을 골라야 하나요?**
특별한 이유가 없다면 SHA-256을 쓰십시오. SHA-384와 SHA-512는 더 긴 값을 만들며 이 역시 문제가 없습니다. SHA-1은 오래된 도구와 시스템이 여전히 SHA-1 값을 공개하기 때문에 남겨 두었으나, 보안 목적으로는 더 이상 안전하다고 보지 않습니다.

**다른 도구와 결과가 다른 이유는 무엇인가요?**
대개 입력에 눈에 보이지 않는 차이가 있기 때문입니다. 줄 끝의 빈 줄이나 다른 문자 인코딩이 원인인 경우가 많습니다. 이 도구는 텍스트를 UTF-8로 읽습니다. 내용을 텍스트로 붙여 넣는 대신 파일 자체의 해시를 구하면 이런 문제를 아예 피할 수 있습니다.

**파일 크기에 제한이 있나요?**
파일 전체를 메모리에 올리므로, 한계는 브라우저와 기기가 담을 수 있는 크기입니다. 수백 메가바이트 정도는 보통 문제가 없지만, 그보다 훨씬 큰 파일은 느려지거나 실패할 수 있습니다.
