## 어떤 도구인가요

Diff 비교 도구는 같은 글의 두 가지 버전을 받아 줄 단위로 나란히 맞춰 줍니다. 양쪽을 번갈아 읽으면서 차이를 찾아내는 대신, 추가된 줄과 삭제된 줄, 그대로인 줄이 한 목록에 표시됩니다.

버전 관리 시스템의 비교 화면과 같은 방식을 붙여 넣은 아무 텍스트에나 적용한 것입니다. 모든 계산은 브라우저 안에서 이루어지므로 입력한 내용이 기기를 벗어나지 않습니다.

## 어떤 때 쓰면 좋은가요

- 설정 파일의 두 버전 가운데 하나를 배포하기 전에 무엇이 달라졌는지 확인할 때.
- 수정된 원고를 원본과 비교해 검토자가 실제로 손댄 문단을 찾아낼 때.
- 두 개의 이름 목록이나 상품 코드, 이메일 주소 목록을 비교해 한쪽에만 있는 항목을 찾을 때.
- 다른 프로그램으로 옮긴 텍스트 블록이 빠짐없이 전달되었는지 확인할 때.
- 긴 키나 경로, 번역된 문장에서 한 글자만 바뀐 부분을 찾아낼 때.

## 사용 방법

이전 버전을 Original 칸에, 새 버전을 Changed 칸에 붙여 넣습니다. 양쪽에 내용이 들어오면 비교 결과가 바로 나타납니다.

각 줄의 왼쪽에는 표시가 붙습니다. 빼기 기호는 원본에만 있는 줄, 더하기 기호는 새 버전에만 있는 줄이며, 표시가 없는 줄은 양쪽이 일치한다는 뜻입니다. 결과 위의 숫자 카드는 각 분류에 몇 줄이 해당하는지 알려 줍니다.

두 개의 선택 항목으로 무엇을 차이로 볼지 조정할 수 있습니다. Ignore whitespace는 이어진 공백과 탭을 같은 것으로 처리하므로, 들여쓰기만 바뀌고 내용은 그대로일 때 유용합니다. Ignore case는 대소문자를 구분하지 않고 비교합니다.

Only changed lines를 켜면 일치하는 줄이 숨겨집니다. 복사 버튼을 누르면 결과를 일반적인 통합 diff 형식으로 가져갈 수 있습니다.

## 자주 묻는 질문

**입력한 내용이 어딘가로 전송되나요?**
전송되지 않습니다. 비교는 브라우저에서 자바스크립트로 계산되며 서버로 아무것도 보내지 않습니다. 네트워크를 끊은 상태에서도 그대로 동작합니다.

**단어 몇 개만 고쳤는데 왜 한 줄이 삭제와 추가로 모두 표시되나요?**
비교가 줄 단위로 이루어지기 때문에 줄 안쪽이 바뀌면 그 줄 전체가 교체된 것으로 표시됩니다. 이전 버전이 삭제로, 새 버전이 추가로 이어서 나오므로 두 줄을 나란히 읽어 볼 수 있습니다.

**얼마나 긴 내용까지 비교할 수 있나요?**
한쪽에 수천 줄 정도까지는 무리가 없습니다. 아주 긴 내용은 화면이 느려지지 않도록 더 단순한 방식으로 비교하기 때문에, 변경된 부분이 줄 단위가 아니라 하나의 큰 덩어리로 묶여 표시될 수 있습니다.
