## 이미지 압축기

## 어떤 도구인가요

휴대폰이나 카메라로 찍은 사진은 필요 이상으로 용량이 큰 경우가 많습니다. 사진 한 장이 수 메가바이트를 차지하기도 하며, 이는 웹 페이지를 느리게 만들고 메일 첨부 용량 제한에 걸리는 원인이 됩니다.

이 도구는 그 용량을 줄여 줍니다. 이미지를 선택하고 가로 폭과 유지할 품질을 정하면 더 작아진 파일을 받을 수 있습니다. 모든 처리는 브라우저 안에서 이루어지므로 이미지가 외부로 전송되지 않습니다.

## 어떤 때에 쓸 수 있나요

- 메일로 보내기 전에 사진을 첨부 용량 제한 아래로 줄일 때
- 웹사이트나 블로그에 올릴 이미지를 가볍게 만들어 로딩 속도를 높일 때
- 용량이 큰 스크린샷이 쌓여 저장 공간을 정리해야 할 때
- 업로드 양식이 용량을 이유로 거부하는 프로필 사진을 줄일 때
- 큰 PNG 스크린샷을 훨씬 가벼운 WebP나 JPG로 바꿀 때

## 사용 방법

이미지 파일을 선택하거나 영역 위로 끌어다 놓습니다. 도구가 해당 이미지의 크기와 원본 용량을 바로 읽어 보여 줍니다.

원하는 최대 가로 폭을 지정합니다. 이미지가 그보다 좁다면 원래 폭이 그대로 유지됩니다. 이어서 출력 형식을 고르고 품질 슬라이더를 움직입니다. 품질을 낮추면 파일이 더 작아집니다.

압축 버튼을 누릅니다. 새 용량이 기존 용량과 함께 표시되고 얼마나 줄었는지 확인할 수 있습니다. 결과가 너무 뭉개졌거나 여전히 무겁다면 설정을 조정해 다시 압축합니다. 만족스러운 결과가 나오면 파일을 내려받습니다.

## 자주 묻는 질문

**이미지가 서버로 전송되나요?**
전송되지 않습니다. 파일은 사용자의 브라우저가 직접 읽어 다시 저장하며, 어디로도 사본이 보내지지 않습니다. 네트워크 연결을 끊은 상태에서도 압축이 정상적으로 동작합니다.

**PNG를 압축했는데 용량이 더 커졌습니다.**
PNG는 모든 픽셀을 그대로 보존하는 형식이라 다시 저장해도 용량이 줄지 않고 오히려 늘어날 수 있습니다. 사진이라면 JPG나 WebP를 선택하시기 바랍니다. PNG는 단색 그래픽이나 로고, 배경이 투명해야 하는 이미지에만 적합합니다.

**PNG에서도 품질 슬라이더가 적용되나요?**
적용되지 않습니다. PNG는 세부 정보를 버리지 않고 픽셀을 저장하므로 품질 설정을 무시합니다. PNG를 선택한 경우에는 가로 폭을 줄이는 것이 용량을 줄이는 방법입니다.

**어떤 형식을 고르면 좋을까요?**
같은 품질에서 가장 작은 용량이 나오는 것은 보통 WebP이며, 현재 사용되는 모든 브라우저에서 열립니다. 오래된 프로그램이나 일반적인 사진 형식만 허용하는 곳에서는 JPG가 가장 안전합니다. 투명한 배경이 필요할 때에는 PNG를 유지하시기 바랍니다.
