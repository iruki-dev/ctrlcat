## What this is

A QR code is a square pattern that a phone camera can read. This tool takes whatever you type and draws that pattern for you. You can then download the result as a PNG image or an SVG file.

Everything happens inside your browser. The text you enter is never sent anywhere, so you can use this for private links and internal notes.

## Where this is useful

Printing a link on a poster, flyer, or business card, so people can reach it without typing a long address.

Putting a menu, price list, or sign-up form on a table tent in a shop or restaurant.

Sharing a Wi-Fi password with guests by encoding the network details once instead of reading them out loud.

Adding a link to a slide deck or a printed report, where a clickable link would not work.

Labelling equipment or storage boxes with a code that points to a manual or an inventory record.

## How to use this tool

Type or paste your text into the box. A QR code appears right away and updates as you edit.

Pick an error correction level. Higher levels add more backup data, so the code still scans when part of it is dirty, faded, or covered. Higher levels also make the pattern denser.

Check the result with your own phone camera before you print anything.

Set the pixel size you want and choose Download PNG for images, or Download SVG when you need a version that stays sharp at any size. You can also copy the SVG markup straight into a web page.

## Frequently asked questions

**Which error correction level should I pick?**
Level M is a sensible default for screens and clean printing. Choose Q or H when the code will be printed small, placed outdoors, or put somewhere it may get scratched or partly covered, such as a sticker on a tool or a label on a crate.

**Why does the pattern get bigger as I type more?**
A QR code holds a fixed amount of data at each grid size. When your text outgrows the current grid, the tool moves up to the next version, which has more rows and columns. Shorter text means a simpler pattern that scans from further away.

**Does the code expire or stop working?**
No. The pattern itself contains your text, so it keeps working forever and needs no service behind it. If you encode a web address, the code keeps pointing at that address, so the page it leads to has to stay online.

**Can I use these codes commercially?**
Yes. The QR code format is open and free to use, and the images you download here are yours to print and publish.
