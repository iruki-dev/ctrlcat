## What this is

Photos from phones and cameras are often far larger than they need to be. A single picture can take up several megabytes, which slows down web pages and bumps into email attachment limits.

This tool reduces that file size. You pick an image, choose how wide it should be and how much quality to keep, and you get a smaller file back. The whole process happens inside your browser, so your image is never uploaded anywhere.

## Where this is useful

- Getting a photo under an email attachment limit before you send it.
- Preparing images for a website or blog so pages load faster.
- Freeing up space when you have a folder of oversized screenshots.
- Shrinking a profile picture that an upload form rejects for being too big.
- Converting a large PNG screenshot into a much lighter WebP or JPG file.

## How to use this tool

Choose an image file, or drag one onto the drop area. The tool reads its dimensions and original size right away.

Set the maximum width you want. If your image is narrower than that, it is left at its own width. Then pick an output format and move the quality slider. Lower quality means a smaller file.

Press Compress. You will see the new size next to the old one and how much you saved. If the result is too soft or still too heavy, adjust the settings and compress again. When you are happy with it, download the file.

## Frequently asked questions

**Is my image uploaded to a server?**
No. The file is read and re-encoded by your own browser, and no copy is sent anywhere. You can even disconnect from the network before compressing and the tool will still work.

**Why did my PNG get bigger instead of smaller?**
PNG keeps every pixel exactly as it is, so re-saving it rarely helps and sometimes adds bytes. For photographs, choose JPG or WebP instead. PNG is the better choice only for flat graphics, logos, and images that need a transparent background.

**Does the quality slider do anything for PNG?**
Not really. PNG ignores the quality setting because it stores pixels without discarding detail. With PNG selected, resizing the image to a smaller width is what reduces the file size.

**Which format should I pick?**
WebP usually gives the smallest file at a given quality and works in every current browser. JPG is the safest option for older software and for anywhere that only accepts classic photo files. Keep PNG when you need transparency.
